# Alec's Telemetry v1.0.1

## Summary
This release refreshes the public setup documentation around the production
Telemetry portal, embedded runtime downloads, Maven/Gradle dependency setup, and
server browser verification.

## Changed
- README links now point at the production portal, runtime downloads, ModStats
  stats, and server browser surfaces.
- Embedded runtime setup docs now include the public Maven repository and both
  Maven and Gradle dependency examples for `alecstelemetry-runtime`.
- Server browser docs now clarify that server operators can verify a server
  profile without owning a mod project.
- The privacy policy now explicitly includes loaded mod names alongside loaded
  mod IDs and versions where that metadata is reported or aggregated.

## Compatibility
- Hytale: 0.5.x

## Files
- Alec's Telemetry v1.0.1.jar
- alecstelemetry-runtime-1.0.1.jar
